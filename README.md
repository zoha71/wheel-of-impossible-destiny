
# Wheel of Impossible Destiny

An interactive, neon-themed physics arcade wheel and AI Coding Lab exercise. The page includes the original spinning wheel, secret outcomes, particle bursts, screen shake, synthesized sound, and chaos setting, plus a simulated command terminal, a three-step mission, a live progress bar, and a Caesar-cipher mini-game.

## Run the app

The app is plain HTML, CSS, and vanilla JavaScript. It has no framework, build step, external library, backend, or API requirement.

- To run it locally, open `index.html` in a current browser.
- To publish it, keep `index.html` at the root of the repository and enable GitHub Pages for the `main` branch and `/(root)` folder.
- The terminal is an in-page simulation. It accepts only the commands listed by `help`; it does not execute operating-system commands.
